# Javy Software – Static Website

Official static website for **Javy Software**, an IT services company offering web development, mobile apps, system development, graphic design, and IT support.

[![PHP](https://img.shields.io/badge/PHP-Static%20Site-777BB4?style=flat&logo=php)](https://php.net)
[![Bootstrap](https://img.shields.io/badge/Bootstrap-Frontend-7952B3?style=flat&logo=bootstrap)](https://getbootstrap.com)

## Overview

This is the company website for **Javy Software**. It presents the company’s services, projects, and contact information in a clean, responsive design.

**Company focus:**
- Website Development (Ecommerce, Static, Service sites)
- System Development
- Mobile App Development (Android & iOS)
- Graphic Design
- IT Support & Online Advertising
- Website Management

## Pages

| Page       | File            | Description                     |
|------------|-----------------|---------------------------------|
| Home       | `index.php`     | Hero slider and introduction    |
| About      | `about.php`     | Company information             |
| Services   | `services.php`  | List of services offered        |
| Projects   | `projects.php`  | Portfolio / past work           |
| Contact    | `contact.php`   | Contact form                    |
| Admin      | `admin.php`     | Admin section (if used)         |

## Tech Stack

- **Backend:** PHP (includes for header/footer)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Icons:** Font Awesome
- **Server:** Apache-compatible (`.htaccess` included)
- **SEO:** Meta tags + Google verification file
